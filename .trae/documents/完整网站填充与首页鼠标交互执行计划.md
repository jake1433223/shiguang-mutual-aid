# 完整网站填充与首页鼠标交互执行计划

## 摘要

本计划承接上一版《简约风改版与完整网站填充计划》中已完成的部分（Three.js 移除、Hero 简约化、Navbar 适配、`.mouse-glow` 工具类），聚焦完成剩余的"完整网站内容填充"工作：

1. 集中管理 mock 数据，为需求广场与详情页提供数据源
2. 首页新增「最新需求」与「用户评价」两个区块，加深内容厚度
3. 新建「需求广场」列表页（筛选 / 排序 / 搜索 + 卡片网格）
4. 新建「需求详情」页（双栏布局 + 接单 CTA + 评论区）
5. 新建 404 NotFound 页，扩展 App.tsx 路由
6. Categories 区块移除 3D Tilt，改为简约 hover 上浮
7. 类型检查 + dev server 浏览器验证

整体保持已确立的简约风格（浅色背景 + 暖石中性色 + brand 绿色强调），鼠标交互以"微微动感"为度（磁性按钮 strength 0.25、`mouse-glow` 柔和光晕、`card-lift` 上浮 -4px、`whileInView` stagger 入场），避免任何炸裂效果。

## 假设与决策

1. **不接后端**：所有数据来自 `mockData.ts`，使用静态数组 + TypeScript 类型，无 fetch / async loading 状态。
2. **不实现真实发布/接单/登录**：按钮均使用 `href="#"` 或 react-router `Link` 跳转，不处理表单提交。
3. **不引入新依赖**：复用现有 framer-motion / lucide-react / react-router-dom / zustand / clsx / tailwind-merge。
4. **设计语言延续**：所有新页面/区块沿用 brand 绿色 + 暖石中性色 + Sora/Noto Serif SC 字体 + 圆角 2xl + `.card-lift` 卡片样式 + `.mouse-glow` 鼠标光晕 + framer-motion stagger 入场。
5. **鼠标交互"微微动感"原则**：
   - 磁性按钮 strength ≤ 0.3
   - 光晕透明度 0.08~0.12
   - 卡片上浮 ≤ 4px
   - 视差位移 ≤ 80px
   - 不使用 perspective / rotate3d / 粒子 / 3D 变换
6. **响应式**：所有新页面遵循移动优先，桌面 max-w-7xl，移动端单列堆叠。
7. **无障碍**：所有交互按钮含 `aria-label`，图标搭配文字，尊重 `prefers-reduced-motion`（`.mouse-glow` 与 framer-motion 已默认降级）。
8. **mock 数据规模**：DEMANDS 12 条（覆盖 6 个分类 + 多种状态）、TESTIMONIALS 4 条、HELPERS 8 个、COMMENTS 4~6 条/需求。
9. **不删 Categories 现有数据**：仅替换 `TiltCard` 子组件为 `HoverCard`，保留 6 个分类数据。

- `DEMANDS: Demand[]`：12 条，分布 6 个分类各 2 条，状态混合（open/in-progress/done）

  - `getDemandById(id: string): Demand | undefined`
  - `getCommentsByDemandId(id: string): Comment[]`
  - `formatRelativeTime(iso: string): string`（"3 天前" / "2 小时前" 等）
  - `CATEGORY_LABELS: Record<DemandCategory, string>`

**Avatar 资源**：使用 `https://api.dicebear.com/9.x/notionists/svg?seed=<name>` 字符串生成（无需 import），或用首字母 + 配色方案生成 div。**决策：用首字母 div 方案**（避免外部图片依赖，符合简约风），avatar 字段存名字，由组件渲染为彩色圆 + 首字母。

**Why**：单一数据源避免散落，类型导出供所有页面/组件复用。
