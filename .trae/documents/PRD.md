## 1. 产品概述

「拾光互助」是一个空闲时间互助平台：用户可发布小需求、用碎片时间帮别人一个忙，让空闲变成彼此的礼物。本项目基于既定设计稿（活力成就风 · 单一绿色品牌色 + 暖石中性色）落地为**完整可运行的 React 单页应用**，并在视觉一致性基础上大幅强化首页的**动感与身临其境感**。

- 目标用户：在校园/职场中有零散小需求或零散空闲时间的个人
- 产品价值：把"几分钟"也变成可被接住的价值单位，并通过积分/排行榜/奖励阶梯形成正向激励闭环

## 2. 核心功能

### 2.1 用户角色
| 角色 | 进入方式 | 核心权限 |

## 4. 用户界面设计

### 4.1 设计风格
- **主色**：单一品牌绿 `#16a34a`（brand-600），辅以 brand-50/100/200/700/800 渐变层次
- **中性色**：暖石色系（stone）从 `#fafaf9` 到 `#0c0a09`
- **按钮风格**：圆角胶囊（`rounded-full`），主按钮实色填充、次按钮描边
- **字体**：标题用衬线/几何感字体（Sora / Noto Serif SC），正文用 PingFang SC / Microsoft YaHei
- **布局**：桌面优先，最大宽度 1280px（max-w-7xl），卡片式布局 + 顶部导航
- **图标**：lucide-react
- **动效基调**：从原稿的"柔软可提起"升级为**"流光涌动 · 身临其境"**——3D 粒子场、鼠标视差、滚动驱动 stagger、磁性按钮、光晕跟随、计数动画

### 4.2 页面设计概览
| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 首页 | Hero | 3D Three.js 粒子流场背景、毛玻璃导航、渐入主标题、计数动画数据、浮动卡片 |
| 首页 | 运作方式 | 三卡片 + 流动箭头 + 滚动 stagger |
| 首页 | 需求分类 | 6 卡片网格 + hover 3D tilt + 光晕 |
| 首页 | 排行榜 | Tab 切换 + 排名徽章 + 行 stagger |
| 首页 | 奖励阶梯 | 三档卡片 + 最高荣誉呼吸光 |
| 首页 | CTA | 渐变背景 + 流动光斑 + 鼠标跟随 |

### 4.3 响应式
- 桌面优先（≥ 1024px）：完整双栏布局、3D 全开
- 平板（768-1023px）：Hero 改为单栏，3D 保留但降低粒子数
- 移动端（< 768px）：单栏堆叠、关闭重型 3D（降级为 CSS 渐变光斑）、导航折叠为汉堡菜单
- 触控优化：禁用磁性按钮等需要鼠标精确追踪的交互，hover 改为 active 态

### 4.4 3D 场景指引（Hero 区）
- **环境**：暗调中性背景上叠加品牌绿粒子流场，营造"光在流动"的氛围
- **粒子系统**：约 1500-2500 个粒子，按 Perlin/Simplex 噪声场流动，鼠标移动产生扰动
- **光照**：环境光 + 点光源（品牌绿 + 暖白），无 HDRI
- **相机**：固定透视相机，轻微呼吸式 dolly zoom
- **后处理**：Bloom（让粒子发光）+ 轻微 ChromaticAberration 增强质感
- **交互**：鼠标移动驱动粒子扰动 + 视差；滚动时相机轻微下移
- **性能预算**：桌面 60fps，移动端降级为 CSS 光斑方案

## 5. 非功能需求
- 性能：首屏 LCP < 2.5s（桌面），3D 场景需懒加载或降级
- 可访问性：尊重 `prefers-reduced-motion`，所有动画在用户偏好下降级
- 浏览器兼容：现代浏览器（Chrome/Edge/Firefox/Safari 最新两个版本）
