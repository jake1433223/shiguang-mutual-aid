# 简约风改版与完整网站内容填充计划

## 摘要

将现有"炸裂 3D Hero 单页营销站"改版为"简约风 + 微微动感 + 鼠标交互"的完整多页网站。核心三件事：
1. **Hero 去炸裂化**：移除 Three.js 2200 粒子 + Bloom 后处理，改为浅色背景 + 鼠标跟随柔和光晕 + 极简渐变流动
2. **首页内容做深**：新增"最新需求"和"用户评价"两个区块，让首页有真实产品感而非纯营销壳
3. **新增功能页**：需求广场列表页（/demands）+ 需求详情页（/demands/:id），覆盖"浏览-接单"核心闭环

整体风格：浅色背景、更多留白、轻微 hover 上浮（不再 3D tilt）、磁性按钮强度降低、保留计数动画与滚动 stagger。

## 当前状态分析

**现有结构**（基于实际探索）：
- 单页应用，仅 `/` 路由（[src/App.tsx](file:///d:/projects/shiguang-mutual-aid/src/App.tsx)）
- [src/pages/HomePage.tsx](file:///d:/projects/shiguang-mutual-aid/src/pages/HomePage.tsx) 组合 6 个 section：Hero / HowItWorks / Categories / Leaderboards / Rewards / JoinCTA
- Hero（[src/components/sections/Hero.tsx](file:///d:/projects/shiguang-mutual-aid/src/components/sections/Hero.tsx)）懒加载 `HeroScene`，2200 粒子 + Bloom + 色差 + 深色背景
- 3D 组件目录 [src/components/three/](file:///d:/projects/shiguang-mutual-aid/src/components/three/) 含 ParticleField / PostFX / HeroScene
- Navbar（[src/components/layout/Navbar.tsx](file:///d:/projects/shiguang-mutual-aid/src/components/layout/Navbar.tsx)）含 `onHero` 深色背景白文字逻辑，锚点导航
- 技术栈：React 18 + TS + Vite + Tailwind v3 + Framer Motion + react-router-dom 7 + Zustand + Three.js
- 设计令牌（[src/index.css](file:///d:/projects/shiguang-mutual-aid/src/index.css)）：品牌绿 brand-600 #16a34a + 暖石中性色，圆角胶囊按钮，保留完好

**问题**：Hero 炸裂感过强不符合"简约"；只有营销内容没有真实产品页；缺少需求列表与详情这两个核心功能页。

## 假设与决策

用户跳过了澄清问题，采用以下默认决策：
- **网站范围**：首页做深 + 需求广场列表页 + 需求详情页（覆盖"浏览-接单"闭环，不做到登录/个人中心以控制范围）
- **Hero 处理**：完全移除 Three.js 3D，改纯 CSS 鼠标交互（最简约、性能最好）
- **风格**：浅色简约、更多留白、微动效
- **保留**：品牌绿色体系、设计令牌、磁性按钮（强度降低）、计数动画、滚动 stagger、滚动进度条
- **移除**：Three.js 全部依赖（drei/fiber/postprocessing/three）、3D Tilt 卡片、Bloom/色差、深色 Hero 背景

### B. Hero 简约化改造

**文件**：[src/components/sections/Hero.tsx](file:///d:/projects/shiguang-mutual-aid/src/components/sections/Hero.tsx)（重写）

**改什么**：
- 移除 `lazy(() => import("@/components/three/HeroScene"))` 与 `<HeroScene />` 挂载
- 背景从 `bg-neutral-950` 深色改为 `bg-background` 浅色（var(--neutral-50)）
- 文字颜色从白色改回 `text-foreground` / `text-muted-foreground`
- 新增鼠标跟随柔和光晕：一个绝对定位的 div，`radial-gradient` 跟随鼠标位置（通过 `onMouseMove` + CSS 变量 `--mx` / `--my`），颜色用 brand-200/300 透明度 0.3-0.4
- 保留极简渐变流动：1-2 个 `glow-orb` 用 `animate-glow-a/b` 缓慢漂移（浅色 brand-100/200）
- 保留：磁性按钮（strength 降到 0.25）、计数动画、滚动视差（contentY/imageY）、stagger 入场
- 主标题"让每一刻空闲 都有人接住"：去掉 shimmer-text 渐变扫光（太花），改为纯色 + 一个词用 brand-600 强调
- 顶部/底部渐变叠加层改为浅色过渡

**为什么**：符合"微微动感 + 简约"，鼠标光晕是核心交互动效。

**怎么做**：重写组件，参考现有结构但替换背景层与颜色。HeroFallbackBg 函数删除（不再需要）。
